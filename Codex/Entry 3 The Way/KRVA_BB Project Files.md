## Overview

This archive contains design specifications for the BB-series autonomous drones. These units are intended for surveillance and data collection operations in restricted zones.

## Technical Specifications

- Frame: Carbon-composite alloy
- Propulsion: Quad-rotor electric drive
- Range: 50km operational radius
- Endurance: 8 hours
- Payload: 2kg sensor package
